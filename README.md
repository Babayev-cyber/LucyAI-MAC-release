# Lucy for Mac

### A Collision product

Lucy is a desktop assistant that helps you work with documents, spreadsheets, and everyday tasks.

## Get Lucy

[Download Lucy for Mac](https://github.com/Babayev-cyber/LucyAI-MAC-release/releases)

Choose the latest Mac installer, open it, and drag Lucy into Applications.
