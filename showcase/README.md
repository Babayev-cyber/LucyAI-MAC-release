# Lucy language showcase

A minimal, standalone template with JavaScript, CSS, HTML, Python, and Rust.
These examples are not Lucy's private application code and do not power the downloads.
GitHub's language percentages describe the files in this public repository, not the private app.

## Try the templates

- Open index.html in a browser and select Say hello.
- Run the Python example with: python main.py
- Run the Rust example with: cargo run --manifest-path Cargo.toml

The Python and Rust programs each print Hello from Lucy! They are independent of the browser example.
No API keys, services, or third-party packages are needed.
